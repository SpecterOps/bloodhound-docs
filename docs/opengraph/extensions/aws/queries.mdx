## Account Resource Inventory

Direct containment edges from each account to the principals and resources it owns. Useful for scoping and visualization.

```cypher
MATCH p=(a:AWS_Account)-[:AWS_Contains]->(n)
RETURN p
LIMIT 1000
```

This query can be imported into BloodHound from the [account-resource-inventory.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/saved_searches/account-resource-inventory.json) file.

## AdministratorAccess Attachments

Every principal (user, role, or group) with the AWS-managed AdministratorAccess policy attached. Baseline for least-privilege review.

```cypher
MATCH p=(n)-[:AWS_HasPolicy]->(:AWS_Policy {arn: "arn:aws:iam::aws:policy/AdministratorAccess"})
RETURN p
LIMIT 1000
```

This query can be imported into BloodHound from the [admin-policy-attachments.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/saved_searches/admin-policy-attachments.json) file.

## Create Identity Provider and Assume Role

Principals that can register a malicious OIDC or SAML identity provider (iam:CreateOpenIDConnectProvider / iam:CreateSAMLProvider) and rewrite a role's trust policy (iam:UpdateAssumeRolePolicy), then assume the role via federation with a token/assertion they control. A direct escalation into the target role.

```cypher
MATCH p=(source)-[:AWS_CanCreateOIDCProviderAndAssumeRole|AWS_CanCreateSAMLProviderAndAssumeRole]->(target:AWS_Role)
RETURN p
LIMIT 1000
```

This query can be imported into BloodHound from the [create-provider-and-assume-role.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/saved_searches/create-provider-and-assume-role.json) file.

## Cross-Account Role Assumption

## Shortest Path From Any User to an Admin Role

Shortest attack path from each IAM user to any role holding AdministratorAccess. Surfaces the cheapest privilege-escalation route to administrative control.

```cypher
MATCH p=shortestPath((u:AWS_User)-[*1..8]->(admin:AWS_Role))
WHERE (admin)-[:AWS_HasPolicy]->(:AWS_Policy {arn: "arn:aws:iam::aws:policy/AdministratorAccess"})
RETURN p
LIMIT 25
```

This query can be imported into BloodHound from the [iam-shortest-path-to-admin.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/saved_searches/iam-shortest-path-to-admin.json) file.

## Workloads and the Roles They Run As

Compute workloads (Lambda functions, EC2 instances, CloudFormation stacks) and the IAM execution role each runs as. Compromising a workload (code replacement, template rewrite, or instance code execution) yields that role's credentials, so these are the next hop from any workload-compromise edge.

```cypher
MATCH p=(w)-[:AWS_RunsAs]->(r:AWS_Role)
RETURN p
LIMIT 1000
```

This query can be imported into BloodHound from the [workload-execution-roles.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/saved_searches/workload-execution-roles.json) file.
