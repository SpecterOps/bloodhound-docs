Principal can call sts:AssumeRoleWithSAML to assume a role via SAML federation.

## Edge Schema

- Source: [AWS_SAMLProvider](/opengraph/extensions/aws/nodes/aws_samlprovider)

## Interpretation

The source is the SAML provider trusted by the role. The collector derives this direction from a same-account federated trust statement allowing `sts:AssumeRoleWithSAML`. Trust conditions remain on the assumption edge; this does not say that any IAM principal can obtain a valid SAML assertion.

## Authorization evidence

Associated API action: `sts:AssumeRoleWithSAML`.

## Evaluation limits

This edge represents the collector's model of collected authorization and resource state. It does not prove that every runtime request succeeds. Inspect unresolved `conditions` and `trust_policy_conditions` when present; `has_conditions` and `has_trust_policy_conditions` indicate retained evidence. Composite edges can include `methods` or `composite_components` describing their derivation.
