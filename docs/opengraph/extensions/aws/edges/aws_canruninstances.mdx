Principal can call ec2:RunInstances (account-scoped) to launch EC2 instances. Wave-0 primitive that, combined with iam:PassRole, feeds the pass_role_via_ec2 composite to run code under a passed instance-profile role.

## Edge schema

| Source kind | Destination kind |
| --- | --- |

| [AWS_User](/opengraph/extensions/aws/nodes/aws_user) | [AWS_Account](/opengraph/extensions/aws/nodes/aws_account) |

**Traversable:** No. This relationship supplies structural or permission evidence and does not independently form an Attack Path step.

## Authorization evidence

Associated API action: `ec2:RunInstances`.

## Evaluation limits

This edge represents the collector's model of collected authorization and resource state. It does not prove that every runtime request succeeds. Inspect unresolved `conditions` and `trust_policy_conditions` when present; `has_conditions` and `has_trust_policy_conditions` indicate retained evidence.
