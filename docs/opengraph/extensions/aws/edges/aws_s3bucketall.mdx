Principal has all S3 bucket permissions (Write + control plane + delete).

## Edge schema

| Source kind | Destination kind |
| --- | --- |
| [AWS_Role](/opengraph/extensions/aws/nodes/aws_role) | [AWS_S3Bucket](/opengraph/extensions/aws/nodes/aws_s3bucket) |
| [AWS_User](/opengraph/extensions/aws/nodes/aws_user) | [AWS_S3Bucket](/opengraph/extensions/aws/nodes/aws_s3bucket) |

**Traversable:** Yes. BloodHound can include this relationship in an Attack Path.

## Composite requirements

The collector combines the following permission kinds for the same principal and target. Their presence must satisfy the collector's evaluation and resource-state checks.

- [AWS_CanDeleteBucket](/opengraph/extensions/aws/edges/aws_candeletebucket)
- [AWS_CanDeleteBucketPolicy](/opengraph/extensions/aws/edges/aws_candeletebucketpolicy)
- [AWS_CanGetBucketACL](/opengraph/extensions/aws/edges/aws_cangetbucketacl)
- [AWS_CanGetBucketPolicy](/opengraph/extensions/aws/edges/aws_cangetbucketpolicy)
- [AWS_CanListBucket](/opengraph/extensions/aws/edges/aws_canlistbucket)
- [AWS_CanPutBucketACL](/opengraph/extensions/aws/edges/aws_canputbucketacl)
- [AWS_CanPutBucketOwnershipControls](/opengraph/extensions/aws/edges/aws_canputbucketownershipcontrols)
- [AWS_CanPutBucketPolicy](/opengraph/extensions/aws/edges/aws_canputbucketpolicy)
- [AWS_CanPutBucketPublicAccessBlock](/opengraph/extensions/aws/edges/aws_canputbucketpublicaccessblock)

## Evaluation limits

This edge represents the collector's model of collected authorization and resource state. It does not prove that every runtime request succeeds. Inspect unresolved `conditions` and `trust_policy_conditions` when present; `has_conditions` and `has_trust_policy_conditions` indicate retained evidence. Composite edges can include `methods` or `composite_components` describing their derivation.
