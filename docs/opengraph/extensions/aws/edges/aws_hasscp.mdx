Organization has a service control policy.

## Edge schema

| Source kind | Destination kind |
| --- | --- |
| [AWS_Account](/opengraph/extensions/aws/nodes/aws_account) | [AWS_ServiceControlPolicy](/opengraph/extensions/aws/nodes/aws_servicecontrolpolicy) |

**Traversable:** No. This relationship supplies structural or permission evidence and does not independently form an Attack Path step.

## Interpretation

The emitted direction is from an account to a service control policy that applies directly or through inheritance. The schema description uses “Organization”; the collector projects this relationship onto affected accounts.
