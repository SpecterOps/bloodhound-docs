## Edge Schema

Traversable: true

Principal can create a new IAM user (iam:CreateUser), grant it admin (iam:AttachUserPolicy/PutUserPolicy on user/*), and mint usable credentials for it (iam:CreateAccessKey/CreateLoginProfile on user/*) — a fresh admin user it controls, gaining account admin. User-side mirror of [AWS_CanCreateAndAssumeAdminRole](/opengraph/extensions/aws/edges/aws_cancreateandassumeadminrole); the methods property records the grant + credential techniques.
