## Edge Schema

Traversable: true

Principal can call cloudformation:UpdateStack to rewrite a stack's template and have CloudFormation execute it as the stack's execution role; the compromise continues to that role via [AWS_RunsAs](/opengraph/extensions/aws/edges/aws_runsas).
