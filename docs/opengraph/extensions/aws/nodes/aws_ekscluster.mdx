An Amazon EKS (managed Kubernetes) cluster, including its Kubernetes version, API endpoint, cluster IAM role, and OIDC issuer used for IRSA.

## Identifier

The node identifier is the resource ARN in `arn`.

## Properties

Types below describe collected values. `null` means the value can be unavailable; it does not make the AWS resource optional. Collection scope and API responses determine which metadata is available.

| Property | Type | Description |
| --- | --- | --- |
| `name` | `str` | Collector-generated name used to identify the resource in context. |
| `displayname` | `str` | Resource label shown in the graph. |
| `arn` | `str or null` | AWS Resource Name used as the node identifier. |
| `account_id` | `str or null` | AWS account associated with the resource; nullable in the shared model. |
| `region` | `str or null` | AWS region, or `global` for resources without a regional scope. |
| `environmentid` | `str` | Account root ARN identifying the OpenGraph environment. |
| `version` | `str or null` | Kubernetes version running on the EKS cluster. |
| `status` | `str or null` | Current EKS cluster status. |
| `endpoint` | `str or null` | Kubernetes API server endpoint. |
| `role_arn` | `str or null` | IAM role ARN used by the EKS control plane. |
| `platform_version` | `str or null` | EKS platform version running on the cluster. |
| `oidc_issuer` | `str or null` | OIDC issuer URL configured for IAM roles for service accounts. |
| `tags` | `list[str] or null` | AWS tags formatted as `key=value` strings. |

## Interpretation

IRSA and Pod Identity edges summarize workload access from the cluster to IAM roles. Review the service-account scope and trust conditions before interpreting access for a particular workload. Kubernetes node kinds belong to a separate extension and are outside this AWS schema inventory.
