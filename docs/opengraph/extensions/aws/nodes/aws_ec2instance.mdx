An Amazon EC2 virtual machine instance, with its instance type, state, VPC/subnet placement, security groups, and attached IAM instance profile.

## Identifier

The node identifier is the resource ARN in `arn`.

## Properties

Types below describe collected values. `null` means the value can be unavailable; it does not make the AWS resource optional. Collection scope and API responses determine which metadata is available.

| Property | Type | Description |
| --- | --- | --- |
| `name` | `str` | Collector-generated name used to identify the resource in context. |
| `displayname` | `str` | Resource label shown in the graph. |
| `arn` | `str or null` | AWS Resource Name used as the node identifier. |
| `account_id` | `str or null` | AWS account associated with the resource; nullable in the shared model. |
| `region` | `str or null` | AWS region, or `global` for resources without a regional scope. |
| `environmentid` | `str` | Account root ARN identifying the OpenGraph environment. |
| `instance_id` | `str` | Native EC2 instance identifier. |
| `launch_time` | `str or null` | Timestamp when the instance was launched. |
| `instance_type` | `str or null` | EC2 instance type. |
| `state` | `str or null` | Current EC2 instance state name. |
| `vpc_id` | `str or null` | VPC identifier containing the instance. |
| `subnet_id` | `str or null` | Subnet identifier containing the instance. |
| `image_id` | `str or null` | AMI identifier used to launch the instance. |
| `private_ip` | `str or null` | Primary private IPv4 address. |
| `public_ip` | `str or null` | Public IPv4 address, when assigned. |
| `iam_instance_profile_arn` | `str or null` | Attached IAM instance profile ARN, when present. |
| `tags` | `list[str] or null` | EC2 tags attached to the instance. |
| `security_groups` | `str or null` | Security groups attached to the instance. |
