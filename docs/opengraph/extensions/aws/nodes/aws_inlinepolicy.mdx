An inline IAM policy attached to an AWS IAM user, group, or role.

## Collection status

This kind is defined in the schema, but the current collector does not emit standalone inline-policy nodes or attachment edges for them. Inline policy documents are stored on IAM user, group, and role nodes in `inline_policies`. There is no emitted identifier or property contract for this kind in this version.
