## Tier Zero Account Roots

The account root principal has unconditional, unrestricted control over every resource in the account and cannot be denied by IAM policies. Every AWS account root is Tier Zero.

Zone: Tier Zero

```cypher
MATCH (n:AWS_Account)
RETURN n
```

This rule is defined in the [t0-accounts.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/privilege_zone_rules/t0-accounts.json) file.

## Tier Zero Groups (AdministratorAccess)

IAM groups with the AWS-managed AdministratorAccess policy attached confer full administrative control on every member. The group is Tier Zero.

Zone: Tier Zero

```cypher
MATCH (n:AWS_Group)-[:AWS_HasPolicy]->(:AWS_Policy {arn: "arn:aws:iam::aws:policy/AdministratorAccess"})
RETURN n
```

This rule is defined in the [t0-admin-groups.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/privilege_zone_rules/t0-admin-groups.json) file.

## Tier Zero IAM Admin-Escalation Principals

Principals with a guaranteed escalation to administrative control: creating and assuming/passing an admin role, or rewriting a policy/trust to assume admin. Possession of any of these is admin-equivalent.

Zone: Tier Zero

```cypher
MATCH (n)-[:AWS_CanCreateAndAssumeAdminRole|AWS_CanCreateAndPassAdminRole|AWS_CanCreateAndAccessAdminUser|AWS_CanUpdateSelfPolicy|AWS_CanUpdateOtherPolicy|AWS_CanUpdateAssumeRolePolicyAndAssume]->()
RETURN n
```

This rule is defined in the [t0-iam-admin-escalation.json](https://github.com/SpecterOps/openhound-aws/tree/main/extension/privilege_zone_rules/t0-iam-admin-escalation.json) file.
