## Okta: Super Administrator Role

The fixed SUPER_ADMIN role grants full management access to an Okta organization. Tag the role, not principals with removable assignments.

Zone: Tier Zero

Enabled: true

Allow disable: true

```cypher
MATCH (n:Okta_Role {type: 'SUPER_ADMIN'})
RETURN n
```

[Source](https://github.com/SpecterOps/openhound-okta/blob/4d81d550df31b12cb7dceaaaa4a70c5f49ed26c6/extension/privilege_zone_rules/super-admin-role.json)
