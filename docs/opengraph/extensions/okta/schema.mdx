## Nodes

| Kind | Description |
| --- | --- |
| [Okta_Agent](/opengraph/extensions/okta/nodes/okta_agent) | A synchronization or authentication agent in Okta |
| [Okta_AgentPool](/opengraph/extensions/okta/nodes/okta_agentpool) | A pool of synchronization or authentication agents in Okta |
| [Okta_ApiServiceIntegration](/opengraph/extensions/okta/nodes/okta_apiserviceintegration) | An API service integration |
| [Okta_ApiToken](/opengraph/extensions/okta/nodes/okta_apitoken) | A secret used by users to authenticate to the Okta API |
| [Okta_Application](/opengraph/extensions/okta/nodes/okta_application) | An application registered in Okta, such as a SAML app or an OIDC app |
| [Okta_AuthorizationServer](/opengraph/extensions/okta/nodes/okta_authorizationserver) | An authorization server in Okta |
| [Okta_ClientSecret](/opengraph/extensions/okta/nodes/okta_clientsecret) | A secret used by applications to authenticate to the Okta API |
| [Okta_CustomRole](/opengraph/extensions/okta/nodes/okta_customrole) | A custom role in Okta created by an administrator |
| [Okta_Device](/opengraph/extensions/okta/nodes/okta_device) | A device registered in Okta, such as a mobile phone or a computer |
| [Okta_Group](/opengraph/extensions/okta/nodes/okta_group) | An Okta user group |
| [Okta_IdentityProvider](/opengraph/extensions/okta/nodes/okta_identityprovider) | An identity provider trusted by Okta for authentication |
| [Okta_JWK](/opengraph/extensions/okta/nodes/okta_jwk) | An Okta JSON Web Key |
| [Okta_Organization](/opengraph/extensions/okta/nodes/okta_organization) | An Okta organization |
| [Okta_Policy](/opengraph/extensions/okta/nodes/okta_policy) | A policy defining rules for authentication, password, or other features in Okta |
| [Okta_Realm](/opengraph/extensions/okta/nodes/okta_realm) | An Okta realm |
| [Okta_ResourceSet](/opengraph/extensions/okta/nodes/okta_resourceset) | A resource set containing users, groups, applications, and other Okta objects |
| [Okta_Role](/opengraph/extensions/okta/nodes/okta_role) | A built-in role in Okta, such as Super Admin or [Group](/resources/nodes/group) Admin |
| [Okta_RoleAssignment](/opengraph/extensions/okta/nodes/okta_roleassignment) | A set of permissions assigned to a user, group, or an application in Okta |
| [Okta_User](/opengraph/extensions/okta/nodes/okta_user) | An Okta user account |
