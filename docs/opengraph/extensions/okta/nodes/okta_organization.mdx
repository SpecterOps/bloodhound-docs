## Overview

The Organization entity represents the Okta tenant itself. It contains general information about the organization, such as its name, domain, and settings.

The Okta organization is represented as a single Okta_Organization node.

## Identity and Investigation

The collector uses the organization's native ID for the node and the same organization ID for its nodes' `environmentid` values. The converter uppercases these identifiers consistently. The configured Okta domain supplies tenant context; it is not a substitute for the organization ID.

Use this node to establish the environment boundary and investigate administrative access to the organization. It is an inherent Tier Zero target. A principal that can reach it through a removable role or membership is an access investigation, rather than a reason to tag that principal as an inherent target.
