Use the Okta extension to investigate administrative access, group membership,
application assignments, credential relationships, and hybrid identity paths in
your Okta organization.

## Collect Okta data

The [OpenHound Okta collector](/openhound/collectors/okta/overview) reads Okta APIs
and converts the results to graph data. Configure a collection identity, install
matching extension assets for your BloodHound edition, and verify ingestion before
investigating paths. Collection scope depends on API authorization, organization
features, and collector options.

The collector can correlate Okta objects with separately collected directory and
application data. Hybrid relationships require matching destination objects and
identifiers; an application assignment alone does not establish downstream access.

## Explore the reference

- [Schema](/opengraph/extensions/okta/schema): supported node and relationship kinds

Individual node pages describe properties and incident relationships. Edge pages
explain direction, traversability, prerequisites, and investigation guidance.
A schema-defined relationship may have collection limitations; review its page
before interpreting missing data.

## Edition-specific capabilities

Graph exploration applies to BloodHound Enterprise and BloodHound Community
Edition. Findings, scheduled collection through an Enterprise collector client,
and the Enterprise extension assets require BloodHound Enterprise. Use the
assets and installation workflow that match your edition and target version.
