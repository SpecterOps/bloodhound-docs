OpenHound Entra Agents is a read-only collector for Microsoft Entra Agent ID,
Copilot Studio, Power Platform connections and flows, Azure AI Foundry, MCP
servers, and external Agent2Agent (A2A) endpoints. It brings agent identities,
ownership, permissions, and configured connections into BloodHound to support
investigations across these services.

The collector extends the Azure graph and connects agent data to AzureHound
objects. Ingest an AzureHound collection for the same tenant before ingesting
Entra Agents data.

## What the collector collects

- Microsoft Entra agent identities, their associated blueprints and blueprint
  principals, agent users, owners, sponsors, and directory roles that permit
  blueprint credential administration.
- Copilot Studio agents, ownership, co-author access, public-agent invocation,
  configured connector and MCP tools, and delegation to other agents and flows.
- Power Platform connection references and their use by agents and flows.
- Connection sharing permissions and supported configured authentication
  identities, when the optional Power Platform management registration is enabled.
- Power Automate flow metadata, ownership, connection references, and child-flow
  relationships.
- Azure AI Foundry projects and agents, associated identities, project
  connections, account and project role assignments, and Key Vault references.
- MCP server metadata and external Agent2Agent (A2A) endpoints referenced in
  agent configurations.

Collection coverage depends on the collector's permissions and the environments
and projects it can access. See [Collector limitations](/openhound/collectors/entra-agents/collector-limitations)
for coverage gaps and guidance on interpreting the results.

## Collection options

Beta users run the collector using the OpenHound container image. Configure the
collector's service principal and secrets using the guides below, then follow
the image deployment instructions provided for the beta.

Choose how to run collection:

| Collection option | Use this option to |
| --- | --- |
| Automated scheduled collection | Run OpenHound as a service to collect and ingest data on a schedule configured for your [OpenHound client](/collect-data/enterprise-collection/create-collector) in BloodHound Enterprise. |
| On-demand collection | Trigger an [on-demand scan](/collect-data/enterprise-collection/on-demand-scan) from BloodHound Enterprise when you need fresh data outside the configured schedule. The OpenHound service must be running. |
| Manual collection | Run the collector yourself, then convert the raw data into OpenGraph JSON files for manual upload to BloodHound Enterprise. Use this option for one-time collections or to inspect the output before ingestion. |

All options require the collector's service principal and permissions for the
services and environments you want to collect.
