The OpenHound AWS collector is the SpecterOps-supported tool for retrieving AWS account and organization data for BloodHound.

## Data collection and privacy

The AWS collector is an open-source, read-only data collector. It requests only **read-only** permissions and never modifies your AWS organization or account.

### What the AWS collector collects

- AWS organization and account metadata
- IAM resources, including users, roles, policies, groups, SAML providers, and OpenID Connect providers
- EC2 instances
- EKS clusters, node groups, access entries, and pod identities
- KMS keys
- Lambda functions
- SSM parameters and managed instances
- CloudFormation stacks and StackSets
- S3 buckets and S3 objects, when S3 collection is enabled

## Collection options

The OpenHound AWS collector supports the following collection options:

| Collection option | Use this option to |
| --- | --- |
| Single AWS profile | Collect data from one AWS account. |
| Multiple AWS profiles | Collect data from multiple independent AWS accounts. |
| AWS organization profile | Collect AWS organization metadata and fan out collection across member accounts. |

All options require read-only AWS permissions. Before you configure the collector, [configure AWS collector permissions](/openhound/collectors/aws/configure-permissions) for your AWS account or organization.
