Choose the collection strategy that matches the AWS environment you want OpenHound to collect:

| Collection strategy | Description |
| --- | --- |
| Organization collection from a dedicated source account | <Icon icon="star"/> **Recommended** The collector's AWS identity, in an account other than the management account, assumes a management role. The collector surveys the organization and assumes the member-account collection role in each active account through the management role. |
| Organization collection from the management account | The collector's AWS identity is already the management role in the organization's management account. The collector surveys the organization and assumes the member-account collection role in each active account. |
| Single-account collection | The collector collects resources from one AWS account, using a profile in an AWS config file that you provide. |
| Multiple independent-account collection | The collector collects resources from multiple AWS accounts that are not connected through one AWS Organization, using profiles in an AWS config file that you provide. |
