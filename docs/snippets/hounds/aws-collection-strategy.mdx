Choose the collection strategy that matches the AWS environment you want OpenHound to collect:

| Collection strategy | Description |
| --- | --- |
| Single-account collection | The collector collects resources from one AWS account. |
| Multiple independent-account collection | The collector collects resources from multiple AWS accounts that are not connected through one AWS Organization. |
| Organization collection from a configured source account | <Icon icon="star"/> **Recommended** Set `source_account` to the account ID of the AWS identity used by the collector. That identity assumes the management role and member-account collection roles. |
| Organization collection from the management account | Omit `source_account` and use an AWS identity that resolves to the organization's management account to collect organization metadata and assume member-account roles. |
