<Warning>
  **Upcoming collector deprecation**
  
  When this feature is enabled, older versions of AzureHound and OpenHound can cause data collection interruptions because BloodHound rejects data from collectors that do not uppercase object IDs.

  Support for older versions of AzureHound and OpenHound will be deprecated in November 2026, so update your collectors to the latest versions as soon as possible.
