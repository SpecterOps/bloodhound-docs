| Property key | Entity panel display name | Description |
| --- | --- | --- |
| `objectid` | Object ID | The unique identifier BloodHound uses for this Azure resource. It is not an Active Directory security identifier (SID). |
| `tenantid` | Tenant ID | Identifier of the Microsoft Entra tenant associated with the resource. |
| `lastcollected` | Last Collected by BloodHound | The most recent time the object was collected and ingested in BloodHound. |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
