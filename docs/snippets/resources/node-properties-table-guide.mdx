- **Property key:** The case-sensitive name used for stored graph properties and API property data. Use stored keys in Cypher, for example, `n.objectid`. Rows marked **API only** are references supplied by entity-information endpoints, not stored Cypher properties.
- **Entity panel display name:** The readable label shown in BloodHound. Use the property key, rather than this label, in queries. A dash means there is no standalone property row or no single property key for the UI status.
- **Directory attribute:** Where present, the source directory attribute. Its name can differ from the BloodHound property key. A dash means no direct directory attribute is listed.

Display names can differ between product versions. A property family such as `composite_*` represents multiple concrete keys; inspect `keys(n)` or `properties(n)` before writing a query.
