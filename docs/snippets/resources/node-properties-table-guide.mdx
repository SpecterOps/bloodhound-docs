- **Property key and value type:** The case-sensitive name used for stored graph properties and API property data, followed by its stored value type on the next line. Use stored keys in Cypher, for example, `n.objectid`. `string[]` means an array of strings; `null` means the collector can return no value. Time values stored as Unix epoch seconds identify that representation explicitly. A dash means the row is a UI status or another value without a stored graph property. Rows marked **API only** are references supplied by entity-information endpoints, not stored Cypher properties.
- **Entity panel display name:** The readable label shown in BloodHound. Use the property key, rather than this label, in queries. A dash means there is no standalone property row or no single property key for the UI status.
- **Directory attribute:** Where present, the source directory attribute. Its name can differ from the BloodHound property key. A dash means no direct directory attribute is listed.

Display names can differ between product versions. Examples appear in descriptions only when they clarify a value format or a constrained set of values. A property family such as `composite_*` represents multiple concrete keys; inspect `keys(n)` or `properties(n)` before writing a query.
