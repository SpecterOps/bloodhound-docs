Your SpecterOps account team will help you install the AWS extension on your BloodHound Enterprise tenant.

After the extension is installed, a collection plan is created, and a collection succeeds, you can explore and analyze AWS data using the following features:

| Feature | Description |
|---|---|
| **Pathfinding** | Use [Pathfinding](/analyze-data/explore/search#pathfinding) to identify attack paths and analyze traversable relationships across all platforms and environments, including built-in and extension-defined kinds. |
| **Saved queries** | Use extension-specific saved queries so you can quickly [search with Cypher](/analyze-data/explore/cypher-search) on the **Explore** page. |
| **Privilege Zone rules** | Create, manage, and optimize extension-specific Privilege Zone [rules](/analyze-data/privilege-zones/rules) to enhance BloodHound's analysis. |
| **Findings and remediation** | Use [findings and remediation](/analyze-data/findings/attack-paths) information to prioritize and address issues in your environment. |
