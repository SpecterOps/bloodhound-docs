Use this guide to troubleshoot deployment and data collection issues with the BloodHound Enterprise CrowdStrike RTR Collector. For installation instructions and required settings, see [Configure the collector](/integrations/crowdstrike/configure).

## Deployment or job execution fails

Review the Log Analytics Workspace or Container App Job execution history for error messages and status codes.

## RTR scripts fail

Confirm that all four scripts are uploaded as cloud-stored scripts, that their file names match the deployment wizard, and that the API client has the required scopes.

## CrowdStrike authentication fails

In the deployment wizard's **CrowdStrike Configuration** step, select **Show advanced settings**. Confirm that the Falcon API region matches the Falcon cloud where the API client was created.

## Azure permissions prevent deployment

Confirm that the deploying user has `Owner`, or both `Contributor` and `User Access Administrator`, on the target subscription.

## Target devices do not return data

Confirm that the Windows devices are online, visible in Falcon, and capable of executing RTR commands.

## Contact support

Contact [SpecterOps Support](/resources/community-support/getting-help#bloodhound-enterprise-support).

## Next steps

After resolving the issue, [verify deployment](/integrations/crowdstrike/configure#verify-deployment) and [verify data ingestion](/integrations/crowdstrike/configure#verify-data-ingestion).
