<Update label="OpenHound" description="Enhancement" tags={["GitHub"]}>
  {/*BED-8788*/}
  ## GitHub Enterprise SSO, SCIM, and Environment Data

  Identify identity, deployment, secret-access, and privilege escalation paths across GitHub enterprises and organizations with expanded enterprise SSO, SCIM, and environment data collection in the OpenHound GitHub collector.

  The OpenHound GitHub collector now supports optional PAT-backed enterprise SSO collection for SAML provider and external identity resources, along with normalized SAML graph output and SCIM graph output for organizations, users, and groups.

  The collector also models environment branch policies, reviewer gates, deployments, environment-scoped secrets and variables, enterprise role capability edges, and visibility-aware organization secret access paths, giving you a clearer view of privilege and secret exposure across your GitHub enterprise.
</Update>

<Update label="OpenHound" description="Enhancement" tags={["Okta"]}>
  {/*BED-9156*/}
  ## Okta Collector Parity Improvements

  Analyze Okta environments with more complete and accurate graph data as the OpenHound Okta collector moves closer to parity with OktaHound, including reworked role assignments, resource sets, hybrid authentication, and normalized SAML modeling.

  This release updates the OpenHound Okta collector to more closely match OktaHound behavior across graph topology, node properties, and edge generation for applications, users, groups, organizations, devices, agents, identity providers, authorization servers, policies, and realms.

  It also adds normalized SAML topology and identity evidence support, including federation providers, service providers, ACS endpoints, claim mappings, account mappings, inbound account resolution, and Org2Org SAML correlation, as an addition to the existing Okta-specific outbound edges. Additional improvements include better retry and rate-limit handling, optional user factor collection, and more resilient handling of missing optional tables.
</Update>
