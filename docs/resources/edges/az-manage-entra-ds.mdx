BloodHound creates this post-processed relationship only when one effective principal has:

1. [AZContributor](/resources/edges/az-contributor) or raw [AZEntraDSContributor](/resources/edges/az-entra-ds-contributor) over the target [AZEntraDS](/resources/nodes/az-entra-ds).
2. Application Administrator in the target tenant.
3. Groups Administrator in the target tenant.

Post-processing accounts for inherited ARM scope, nested Azure group membership, and effective Entra role assignments.

## Composition

Composition exposes the effective ARM assignment, group-membership and resource-containment paths together with the Application Administrator and Groups Administrator role paths. All three permission components must apply to the same source principal.

## Abuse Info

The source can change the managed domain's security configuration and broad synchronization boundary. Live validation confirmed changes to a representative security setting, `syncScope`, and `filteredSync` only when the complete conjunction was present.

### Procedure

1. Obtain an Azure Resource Manager access token and all three authorization components represented by the edge: `AZContributor` or `AZEntraDSContributor`, Application Administrator, and Groups Administrator.
2. Read the Microsoft Entra Domain Services (Entra DS) resource and retain its location and current nested settings:

   ```http
   GET https://management.azure.com/{resource-id}?api-version=2025-06-01
   ```

3. Choose a supported management-plane change. To change identity synchronization, see [ManageEntraDSSync](/resources/edges/manage-entra-ds-sync).
4. Submit the change with:

   ```http
   PUT https://management.azure.com/{resource-id}?api-version=2025-06-01
   ```

## Edge Schema

Source: [AZUser](/resources/nodes/az-user), [AZGroup](/resources/nodes/az-group), or [AZServicePrincipal](/resources/nodes/az-service-principal)<br />
Destination: [AZEntraDS](/resources/nodes/az-entra-ds)<br />
Traversable: **Yes**
