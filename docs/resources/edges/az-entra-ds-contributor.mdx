This relationship records raw Azure Resource Manager authorization. The built-in Domain Services Contributor role, definition ID `eeaeda52-9324-47f6-8069-5d5bade478b2`, grants `Microsoft.AAD/domainServices/*` and related network permissions over the target [AZEntraDS](/resources/nodes/az-entra-ds).

The edge is not independently traversable. BloodHound creates [AZManageEntraDS](/resources/edges/az-manage-entra-ds) only when the same effective principal also has Application Administrator and Groups Administrator.

## Abuse Info

This assignment supplies the Azure Resource Manager portion of managed-domain configuration changes. It is insufficient by itself or when combined with only one of Application Administrator or Groups Administrator. When the same effective principal also has both Entra roles, BloodHound creates the traversable [AZManageEntraDS](/resources/edges/az-manage-entra-ds) edge.

## Opsec Considerations

Azure records managed-domain updates in the Activity Log. Synchronization-scope changes can also generate Microsoft Entra audit activity and trigger a full managed-domain resynchronization, including deletion of objects that fall out of scope.

## Edge Schema

Source: [AZUser](/resources/nodes/az-user), [AZGroup](/resources/nodes/az-group), or [AZServicePrincipal](/resources/nodes/az-service-principal)<br />
Destination: [AZEntraDS](/resources/nodes/az-entra-ds)<br />
Traversable: **No**
