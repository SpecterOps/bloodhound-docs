## Representation

The **MemberOfZone** edge connects a graph node to the synthetic [Zone](/resources/nodes/zone) node for the [privilege zone](/analyze-data/privilege-zones/overview) that contains it. BloodHound Enterprise generates and reconciles these edges during analysis from current privilege-zone membership.

This edge represents zone membership for graph analysis. It is not a collected directory relationship. An object is tagged as a member of a zone when it matches one of the zone's rules.

## Edge schema

Source: Any non-synthetic graph node assigned to the privilege zone<br/>
Destination: [Zone](/resources/nodes/zone)<br/>
Traversable: ✅

## Use in analysis

BloodHound Enterprise uses Zone nodes as reference points when calculating a finding target's proximity to Tier Zero. `MemberOfZone` is a traversable edge, so analysis and pathfinding follow it from a zone member to its Zone node.

On the **Explore** page, you can include or exclude the edge in pathfinding with the **Common** > **Privilege Zones** category of the edge filter.

Use the relationship in Cypher queries when you need to identify the nodes assigned to a privilege zone.
