## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname`<br />`string` | Display Name | The display name for the object. |
| `objectid`<br />`string` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `whencreated`<br />Unix epoch seconds | Created | The time when the object was created in the directory. |
| `description`<br />`string` | Description | The contents of the `description` field for the object. |
| `isassignabletorole`<br />`boolean` | Is Role Assignable | Whether this group can receive Microsoft Entra role assignments. This does not mean that a role is currently assigned.<br /><br />Find this in Microsoft Entra admin center: Entra ID → Groups → All groups → Add filters → Role assignable. |
| `onpremsyncenabled`<br />`boolean` | On-Premises Sync Enabled | Reports whether this object is synchronized from an on-premises directory.<br /><br />Source attribute in Microsoft Graph: `onPremisesSyncEnabled` on the user or group object. |
| `securityenabled`<br />`boolean` | Security Enabled | Whether the group is a Security Principal, meaning it can be used to secure objects in Entra ID. |
| `securityidentifier`<br />`string` | Security Identifier | The group’s security identifier reported by Microsoft Graph for Windows scenarios. This differs from the synchronized on-premises SID in `onpremid`. |
| `tenantid`<br />`string` | Tenant ID | Unique identifier for the Azure tenant. |
| `onpremid`<br />`string` | On-Premises ID | The security identifier (SID) of the corresponding on-premises Active Directory object.<br /><br />Source attribute in Microsoft Graph: `onPremisesSecurityIdentifier` on the user or group object. |
