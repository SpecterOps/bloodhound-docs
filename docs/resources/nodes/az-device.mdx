## Node properties

<NodePropertiesTableGuide />

| Property key | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname` | Display Name | The display name for the object. |
| `objectid` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `tenantid` | Tenant ID | Unique identifier for the Azure tenant. |
| `trustype` | Trust Type | The device’s join relationship with Microsoft Entra ID: AzureAd means Entra joined, Workplace means Entra registered, and ServerAd means Entra hybrid joined.<br /><br />Find this in Microsoft Entra admin center: Entra ID → Devices → All devices → Join type. |
