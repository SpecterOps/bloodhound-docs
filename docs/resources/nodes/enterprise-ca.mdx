## Representation

The EnterpriseCA node represents the Active Directory LDAP objects of the _pKIEnrollmentService_ class located in the _Enrollment Services_ container in the Configuration Naming Context.

## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Directory attribute | Description |
| --- | --- | --- | --- |
| `objectid`<br />`string` | Object ID | `objectGUID` | The object's unique identifier in the directory. |
| `isaclprotected`<br />`boolean` | ACL Inheritance Denied | `nTSecurityDescriptor` | Whether the object’s discretionary access control list (DACL) blocks inherited access control entries (ACEs). |
| `basicconstraintpathlength`<br />`integer` | Basic Constraint Path Length | `caCertificate` (`X509Certificate`) | The maximum number of non-self-issued intermediate certificates that may follow this certificate in a valid certificate chain. |
| `caname`<br />`string` | CA Name | `name` | Name of the CA in the directory. |
| `casecuritycollected`<br />`boolean` | CA Security Collected | - | Whether the Security ACL stored in registry of the CA host has been collected. |
| `certchain`<br />`string[]` | Certificate Chain | `caCertificate` (`X509Certificate`) | A hierarchical list of certificates starting with the certificate for this CA and ending with a self-signed root certificate. Each certificate is signed by the private key of the next CA certificate. |
| `certname`<br />`string` | Certificate Name | `caCertificate` (`X509Certificate`) | The name of the CA's certificate. |
| `certthumbprint`<br />`string` | Certificate Thumbprint | `caCertificate` (`X509Certificate`) | The thumbprint (unique identifier) of the CA's certificate. |
| `whencreated`<br />Unix epoch seconds | Created | `whenCreated` | When the object was created in the directory. |
| `distinguishedname`<br />`string` | Distinguished Name | `distinguishedName` | The name of the object and its location in AD. |
| `dnshostname`<br />`string` | DNS Hostname | `dNSHostName` | The DNS host name of the CA host. |
| `domain`<br />`string` | Domain FQDN | - | The fully qualified domain name (FQDN) of the domain the object belongs to. |
| `domainsid`<br />`string` | Domain SID | - | The SID of the domain the object belongs to. |
| `enrollmentagentrestrictionscollected`<br />`boolean` | Enrollment Agent Restrictions Collected | - | Whether the EnrollmentAgentRights ACL stored in registry of the CA host has been collected. |
| `flags`<br />`string` | Flags | `flags` | Various flags controlling features of the enrollment service. |
| `hasbasicconstraints`<br />`boolean` | Has Basic Constraints | `caCertificate` (`X509Certificate`) | Whether the CA certificate has basic constraints. |
| `hasenrollmentagentrestrictions`<br />`boolean` | Has Enrollment Agent Restrictions | - | Whether the enrollment agent restrictions are enabled. |
| `isuserspecifiessanenabledcollected`<br />`boolean` | User Supplied SAN Setting Collected | - | Whether the EditFlags registry value of the CA host has been collected. |
| `isuserspecifiessanenabled`<br />`boolean` | User Supplied SAN Enabled | - | Reports the CA policy flag that accepts subject alternative names supplied as certificate-request attributes.<br /><br />Find this in Command Prompt on the CA: `certutil -getreg policy\EditFlags`; inspect `EDITF_ATTRIBUTESUBJECTALTNAME2`. |
| `lastcollected`<br />`string` | Last Collected by BloodHound | - | The most recent time the object was collected and ingested in BloodHound. |
| `lastseen`<br />`string` | Last Seen by BloodHound | - | The most recent time the object or a reference to it was collected and ingested in BloodHound. |
| `roleseparationenabledcollected`<br />`boolean` | Role Separation Enabled Collected | - | Whether the RoleSeparationEnabled registry value of the CA host has been collected. |
| `roleseparationenabled`<br />`boolean` | Role Separation Enabled | - | Whether the CA host enforces role separation i.e. users are not permitted to have the CA Administrator role and if they have the Certificate Manager role and vice versa; |
| `unresolvedpublishedtemplates`<br />`string[]` | Unresolved Published Certificate Templates | `certificateTemplates` | The published certificate templates which could not be found. |
| `name`<br />`string` | — | `name` + domain name | Name of the object + @ + the name of the domain. |
