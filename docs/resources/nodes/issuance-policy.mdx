## Representation

The IssuancePolicy node represents the Active Directory LDAP objects of the _msPKI-Enterprise-Oid_ class located in the _OID_ container in the Configuration Naming Context.

## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Directory attribute | Description |
| --- | --- | --- | --- |
| `objectid`<br />`string` | Object ID | `objectGUID` | The object's unique identifier in the directory. |
| `isaclprotected`<br />`boolean` | ACL Inheritance Denied | `nTSecurityDescriptor` | Whether the object’s discretionary access control list (DACL) blocks inherited access control entries (ACEs). |
| `certtemplateoid`<br />`string` | Certificate Template OID | `msPKI-Cert-Template-OID` | The OID string used in certificate templates to reference this issuance policy. |
| `whencreated`<br />Unix epoch seconds | Created | `whenCreated` | When the object was created in the directory. |
| `distinguishedname`<br />`string` | Distinguished Name | `distinguishedName` | The name of the object and it's location in AD. |
| `domain`<br />`string` | Domain FQDN | - | The fully qualified domain name (FQDN) of the domain the object belongs to. |
| `domainsid`<br />`string` | Domain SID | - | The SID of the domain the object belongs to. |
| `lastcollected`<br />`string` | Last Collected by BloodHound | - | The most recent time the object was collected and ingested in BloodHound. |
| `lastseen`<br />`string` | Last Seen by BloodHound | - | The most recent time the object or a reference to it was collected and ingested in BloodHound. |
| `name`<br />`string` | — | `name` + domain name | Name of the object + @ + the name of the domain. |
