## Representation

The ADLocalGroup node represents a local group on a domain computer.

## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Directory attribute | Description |
| --- | --- | --- | --- |
| `objectid`<br />`string` | Object ID | - | The object's unique identifier in the directory. |
| `lastcollected`<br />`string` | Last Collected by BloodHound | - | The most recent time the object was collected and ingested in BloodHound. |
| `lastseen`<br />`string` | Last Seen by BloodHound | - | The most recent time the object or a reference to it was collected and ingested in BloodHound. |
| `name`<br />`string` | — | Group name + computer FQDN | Name of the group + @ + the FQDN of the computer which it exists on. |
