## Node properties

<NodePropertiesTableGuide />

| Property key | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `objectid` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `federatedidentitycredentialappid`<br />API only | Federated Identity Credential Application ID | The related [AZApp](/resources/nodes/az-app) that contains this federated identity credential. The API adds this reference from the application relationship; it is not a stored Cypher property. |
| `audiences` | Audiences | The audiences claim that identifies the intended recipients of the token issued by this FIC. |
| `issuer` | Issuer | The entity that issues the token, typically the external identity provider. |
| `lastseen` | Last Seen by BloodHound | The most recent time that BloodHound observed this object in an ingested data payload. |
| `subject` | Subject | The subject claim that identifies the principal allowed to authenticate via this FIC. |
