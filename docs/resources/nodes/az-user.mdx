## Node properties

<NodePropertiesTableGuide />

| Property key | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname` | Display Name | The display name for the object. |
| `objectid` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `whencreated` | Created | The time when the object was created in the directory. |
| `enabled` | Enabled | Whether the account or identity is enabled. |
| `onpremsyncenabled` | On-Premises Sync Enabled | Reports whether this object is synchronized from an on-premises directory.<br /><br />Source attribute in Microsoft Graph: `onPremisesSyncEnabled` on the user or group object. |
| `pwdlastset` | Password Last Set | The human-readable date for when the user’s password last changed. This is stored internally in Unix epoch format |
| `tenantid` | Tenant ID | Unique identifier for the Azure tenant. |
| `userprincipalname` | User Principal Name | The user's login name following the format of an email address, typically mapped to the user's email address |
| `usertype` | User Type | The user’s directory classification, such as Member or Guest. This classification does not by itself identify where the user authenticates.<br /><br />Find this in Microsoft Entra admin center: Entra ID → Users → select the user → Overview → User type. |
| `lastsuccessfulsignindatetime` | Last Successful Sign-In | The most recent successful interactive or non-interactive sign-in reported for this user.<br /><br />Source attribute in Microsoft Graph: `signInActivity.lastSuccessfulSignInDateTime` on the user object. |
| `onpremid` | On-Premises ID | The security identifier (SID) of the corresponding on-premises Active Directory object.<br /><br />Source attribute in Microsoft Graph: `onPremisesSecurityIdentifier` on the user or group object. |
