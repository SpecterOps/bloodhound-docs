## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname`<br />`string` | Display Name | The display name for the object. |
| `objectid`<br />`string` | Object ID | The object's security identifier (SID), a unique identifier in the directory. |
| `isaclprotected`<br />`boolean` | ACL Inheritance Denied | Whether the object’s discretionary access control list (DACL) blocks inherited access control entries (ACEs). |
| `whencreated`<br />Unix epoch seconds | Created | The time when the object was created in the directory. |
| `description`<br />`string` | Description | The contents of the `description` field for the object. |
| `functionallevel`<br />`string` | Functional Level | The functional level of the Active Directory domain. This becomes particularly relevant in certain attack scenarios, such as resource-based constrained delegation. |
| `machineaccountquota`<br />`integer` | Machine Account Quota | The domain quota for computer accounts that a user can create without separately delegated computer-creation permissions.<br /><br />Find this in ADSI Edit: connect to the Default naming context → domain object Properties → ms-DS-MachineAccountQuota. |
| `dsheuristics`<br />`string` | Directory Service Heuristics | A forest-wide string of Directory Service settings, with individual character positions controlling different behavior.<br /><br />Find this in ADSI Edit: connect to the Configuration naming context → CN=Services → CN=Windows NT → CN=Directory Service → Properties → dSHeuristics. |
