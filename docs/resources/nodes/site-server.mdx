## Representation

The SiteServer node represents an Active Directory `server` object under a site's `Servers` container. A [ServerIs](/resources/edges/server-is) relationship connects it to the corresponding [Computer](/resources/nodes/computer) object through the directory object's `serverReference` attribute.

By default, a SiteServer linked to a domain controller is classified as Tier Zero / High Value. This lets BloodHound surface the impact of a compromised [Site](/resources/nodes/site): a malicious GPO linked to the site can apply to the domain controller represented by the SiteServer.

## Node properties

<NodePropertiesTableGuide />

| Property key | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname` | Display Name | The display name for the server object. |
| `objectid` | Object ID | The server object's object GUID, a unique identifier in Active Directory. |
| `serverreferencecomputer`<br />API only | Referenced Computer | The related [Computer](/resources/nodes/computer), resolved through [ServerIs](/resources/edges/server-is). The API reference differs from the stored `serverreference` directory data. |
| `whencreated` | Created | The time when the server object was created in the directory. |
| `description` | Description | The contents of the `description` field for the server object. |
