## Node properties

<NodePropertiesTableGuide />

| Property key | Entity panel display name | Description |
| --- | --- | --- |
| `displayname` | Display Name | The display name for the object. |
| `objectid` | Object ID | The object’s GUID, a unique identifier in Active Directory. |
| `isaclprotected` | ACL Inheritance Denied | Whether the object’s discretionary access control list (DACL) blocks inherited access control entries (ACEs). |
