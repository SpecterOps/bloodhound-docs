## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname`<br />`string` | Display Name | The display name for the object. |
| `objectid`<br />`string` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `appdisplayname`<br />`string` | App Display Name | The display name for the application. |
| `appownerorganizationid`<br />`string` | App Owner Organization ID | The tenant ID of the organization where the associated application is registered. Applies to service principals backed by an application.<br /><br />Source attribute in Microsoft Graph: `appOwnerOrganizationId` on the service principal object. |
| `serviceprincipaltype`<br />`string` | Service Principal Type | Whether this service principal represents an application, a managed identity, or a legacy application.<br /><br />Source attribute in Microsoft Graph: `servicePrincipalType` on the service principal object. |
| `tenantid`<br />`string` | Tenant ID | Unique identifier for the Azure tenant. |
