## Representation

The AIACA node represents the Active Directory LDAP objects of the _certificationAuthority_ class located in the _AIA_ container in the Configuration Naming Context.

## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Directory attribute | Description |
| --- | --- | --- | --- |
| `objectid`<br />`string` | Object ID | `objectGUID` | The object's unique identifier in the directory. |
| `isaclprotected`<br />`boolean` | ACL Inheritance Denied | `nTSecurityDescriptor` | Whether the object’s discretionary access control list (DACL) blocks inherited access control entries (ACEs). |
| `basicconstraintpathlength`<br />`integer` | Basic Constraint Path Length | `caCertificate` (`X509Certificate`) | The maximum number of non-self-issued intermediate certificates that may follow this certificate in a valid certificate chain. |
| `certchain`<br />`string[]` | Certificate Chain | `caCertificate` (`X509Certificate`) | A hierarchical list of certificates starting with the certificate for this CA and ending with a self-signed root certificate. Each certificate is signed by the private key of the next CA certificate. |
| `certname`<br />`string` | Certificate Name | `caCertificate` (`X509Certificate`) | The name of the CA's certificate. |
| `certthumbprint`<br />`string` | Certificate Thumbprint | `caCertificate` (`X509Certificate`) | The thumbprint (unique identifier) of the CA's certificate. |
| `whencreated`<br />Unix epoch seconds | Created | `whenCreated` | When the object was created in the directory. |
| `distinguishedname`<br />`string` | Distinguished Name | `distinguishedName` | The name of the object and it's location in AD. |
| `domain`<br />`string` | Domain FQDN | - | The fully qualified domain name (FQDN) of the domain the object belongs to. |
| `domainsid`<br />`string` | Domain SID | - | The SID of the domain the object belongs to. |
| `hasbasicconstraints`<br />`boolean` | Has Basic Constraints | `caCertificate` (`X509Certificate`) | Whether the CA certificate has basic constraints. |
| `hascrosscertificatepair`<br />`boolean` | Has Cross Certificate Pair | `crossCertificatePair` | Whether the CA has trust to any external certificate. |
| `lastcollected`<br />`string` | Last Collected by BloodHound | - | The most recent time the object was collected and ingested in BloodHound. |
| `lastseen`<br />`string` | Last Seen by BloodHound | - | The most recent time the object or a reference to it was collected and ingested in BloodHound. |
| `crosscertificatepair`<br />`string[]` | Cross Certificate Pair | `crossCertificatePair` | List of external certificates trusted by the CA. |
| `name`<br />`string` | — | `name` + domain name | Name of the object + @ + the name of the domain. |
