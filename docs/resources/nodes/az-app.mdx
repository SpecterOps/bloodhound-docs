## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Description |
| --- | --- | --- |
| — | Tier Zero | Whether BloodHound classifies the object as Tier Zero. This UI status is not a stored `highvalue` node property. |
| `displayname`<br />`string` | Display Name | The display name for the object. |
| `objectid`<br />`string` | Object ID | The unique identifier BloodHound uses for this Entra or Azure object. It is not an Active Directory security identifier (SID). |
| `whencreated`<br />Unix epoch seconds | Created | The time when the object was created in the directory. |
| `description`<br />`string` | Description | The contents of the `description` field for the object. |
| `publisherdomain`<br />`string` | Publisher Domain | The domain of the application publisher. |
| `service_principal_id`<br />API only | Service Principal ID | The related [AZServicePrincipal](/resources/nodes/az-service-principal), resolved through the application’s [RunsAs](/resources/edges/az-runs-as) relationship. This API-derived reference is not a stored Cypher property. |
| `signinaudience`<br />`string` | Sign-In Audience | The account types the application is configured to support, such as one organization, multiple organizations, or personal Microsoft accounts.<br /><br />Find this in Microsoft Entra admin center: Entra ID → App registrations → select the application → Manifest → `signInAudience`. |
| `tenantid`<br />`string` | Tenant ID | Unique identifier for the Azure tenant. |
