## Representation

Meta nodes represent a set of related nodes. They are created and used by analysis in order to support attack path mapping for different zones and environments. These nodes do not directly represent any actual entity from collected environments. As their name suggests, Meta nodes hold metadata for attributing and rendering attack path details for their associated zone and environment.

## Node properties

<NodePropertiesTableGuide />

| Property key and value type | Entity panel display name | Description |
| --- | --- | --- |
| `lastseen`<br />`string` | Last Seen by BloodHound | The most recent time the object or a reference to it was collected and ingested in BloodHound. |
| `owner_objectid`<br />`string` | Owner Object ID | The object ID for the environment the Meta node is associated with |
| `principal_count`<br />`integer` | Principal Count | The number of principals in the set the Meta node represents |
| `date`<br />— | Date | ISO time string when the node was created |
| `composite_*`<br />Varies | Varies by property | Counts of associated node types. The asterisk denotes multiple concrete keys, not a literal property name. Inspect `keys(n)` or `properties(n)` to find the available keys. |

## Edges

Any [traversable](/resources/edges/traversable-edges#traversable-edges) edge type may be linked to/from this node.
